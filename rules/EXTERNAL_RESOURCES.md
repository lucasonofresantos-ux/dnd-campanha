# Recursos Externos do Mestre RPG

Este arquivo cataloga recursos públicos úteis ao Mestre. Eles são referências externas: não são copiados integralmente para este repositório.

## Oficial
- D&D SRD 5.2.1 — https://www.dndbeyond.com/srd
  Autoridade primária aberta para regras.

## Repositórios públicos estruturados
- https://github.com/adkinn/srd-5.2.1
  SRD 5.2.1 em formato estruturado; útil para consulta por máquina e integrações.

- https://github.com/5e-bits/5e-srd-api
  API/base estruturada de conteúdo SRD.

- https://github.com/foundryvtt/dnd5e
  Implementação do sistema D&D5e no Foundry VTT; referência complementar de implementação.

- https://github.com/open5e/open5e-api
  API/agregador de conteúdo aberto 5e. Pode incluir conteúdo de terceiros e não deve ser confundido com material oficial da Wizards.

## Regra de uso pelo Mestre
1. Para decidir regra oficial, priorizar o SRD 5.2.1.
2. Usar bases estruturadas para localizar/organizar informação, não para sobrepor a fonte oficial.
3. Identificar conteúdo de terceiros antes de introduzi-lo na campanha.
4. Não importar automaticamente conteúdo novo para o cânone da campanha.
5. Não copiar material comercial protegido para este repositório.
