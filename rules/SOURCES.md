# Fontes de Regras

## Hierarquia de autoridade

### Nível 1 — Oficial / canônico de regras
- D&D System Reference Document v5.2.1 (Wizards of the Coast).
- É a referência aberta primária para decisões mecânicas desta campanha.
- Em caso de conflito com implementações ou bases de terceiros, o SRD prevalece.

### Nível 2 — Dados estruturados / implementações de referência
Estas fontes facilitam pesquisa e validação, mas não substituem o SRD oficial:

- adkinn/srd-5.2.1 — representação estruturada do SRD 5.2.1 e recursos voltados a integração/MCP.
  https://github.com/adkinn/srd-5.2.1

- 5e-bits/5e-srd-api — API e base estruturada para conteúdo SRD de D&D 5e.
  https://github.com/5e-bits/5e-srd-api

- foundryvtt/dnd5e — implementação pública do sistema D&D5e para Foundry VTT; útil para referência de implementação, não como autoridade superior ao SRD.
  https://github.com/foundryvtt/dnd5e

### Nível 3 — Conteúdo aberto de terceiros
- Open5e — agregador/API de conteúdo 5e aberto de múltiplas fontes.
  https://github.com/open5e/open5e-api

Conteúdo proveniente deste nível deve ser identificado como terceiro e nunca apresentado como regra oficial da Wizards of the Coast.

## Regras próprias da campanha
Regras deliberadamente aprovadas para esta mesa ficam em HOUSE_RULES.md. Uma decisão improvisada do Mestre não vira automaticamente house rule permanente.

## Ordem para resolver conflitos
1. SRD 5.2.1 oficial.
2. House rule explicitamente aprovada e registrada para a campanha.
3. Interpretação coerente registrada para a campanha quando o SRD não resolver a questão.
4. Implementações/fontes estruturadas de Nível 2.
5. Conteúdo aberto de terceiros, somente quando deliberadamente adotado.

## Política de conteúdo e copyright
Não armazenar neste repositório cópias não autorizadas de livros, aventuras ou outros materiais comerciais. Materiais de terceiros devem ser identificados como tais. Aventuras e conteúdo comercial só serão usados dentro dos limites de acesso legítimo do usuário ou de fontes autorizadas.

O repositório dnd-campanha armazena principalmente estado, resumos, decisões e registros da campanha; ele não deve funcionar como cópia de livros comerciais.
